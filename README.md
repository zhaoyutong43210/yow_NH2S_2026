## 关于"Liu Yanjun"的安省法庭记录

编者按，Yanjun Liu 在2021年秋季学期于渥太华大学医学院PHD项目博士入学，2024年5约21日，以1年制授课型硕士项目毕业，该项目含有8个月的课程以及一个研究性项目。期间经历了共2年10个月。具体其合适从博士项目转为硕士项目不得而知。

但是根据历史不难推测， Yanjun Liu 的逻辑为： 她最终毕业的是硕士项目，因此她之前按博士项目的缴费她并没有按预期使用，因此其在渥太华大学博士项目期间的学费应退还。
